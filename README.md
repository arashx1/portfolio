# Arash / Portfolio

Original, Persona-menu-inspired portfolio for Arashdeep Singh. Buildless HTML, CSS and JavaScript. Content is based on the existing Framer portfolio inspected on 22 October 2026. Reference: https://github.com/Numal400/Persona_style_portfolio . No reference code, characters, videos or sound files were copied.

## Open

Open index.html directly, or in this folder run:

```powershell
python -m http.server 5501 --bind 127.0.0.1
```

Then visit http://127.0.0.1:5501 . VS Code Live Server also works. No npm install or build needed. Google Fonts improves the typography; system fonts are available offline.

## Edit

- `index.html`: biography, navigation, contact details and original SVG hero artwork.
- `app.js`: project descriptions, destinations, toolkit and interaction logic.
- `style.css`: palette, layouts, responsive rules and motion.

Projects open accessible modal dossiers. Filter by product or AI. Arrow keys select navigation items when navigation/main has focus; Enter opens them. Escape closes a dossier or returns home. Sound is opt-in and synthesized locally. Reduce Motion follows the operating system and offers a manual toggle.
